# Wheel downloads

When this Release is published to PyPI, the recommended installation uses its
`uc-manager[extra]` package. This page also lists the meta Wheel, every backend
Wheel, Python ABI, architecture, manylinux platform, and direct Release asset
link.

Install only one backend extra in a fresh Python environment. Different backend
packages own the same `ucm` import namespace and must not be combined.
